# Step 03 — numbers before geometry

```
Read side.png and front.png. Before modelling anything, write parts.json:
every part of the [object] with its start and end along the length in cm
(from the back end), its height, width, colour and which part it attaches to.
Show me the list and wait for my OK.
```

Save the approved file as `examples/props/<name>/parts.json` (use metres in this repo).
